# 📊 Mobile Sales Dashboard – Power BI

An interactive Power BI dashboard designed to analyze mobile phone sales,
transactions, customer ratings, payment methods, brands, and sales trends.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📌 Dashboard KPIs

- Total Sales: 769M
- Total Quantity: 19K
- Transactions: 4K
- Average Sales: 40K

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Total Sales by City
- Total Quantity by Month
- Total Sales by Mobile Model
- Transactions by Payment Method
- Customer Ratings
- Total Sales by Day Name
- Brand-wise Sales and Quantity

## 🔍 Key Features

- Interactive filters for Mobile Model, Payment Method, Brand and Day Name
- Monthly sales/quantity analysis
- City-wise sales visualization
- Brand performance comparison
- Payment method analysis
- Customer rating analysis
- Interactive Power BI visuals
